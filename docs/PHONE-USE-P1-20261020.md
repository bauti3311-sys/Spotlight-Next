## Código integrado
- `agent/PhoneUseService.kt`: `AccessibilityService` separado y voluntario; inspección explícita, pulsación y escritura exacta sobre controles de una app externa.
- `agent/PhoneUsePolicy.kt`: validación de paquetes, bloqueo de pantallas privilegiadas, selectores `id:`, `text:`, `desc:`, texto acotado.
- `ToolRegistry`: `screen_inspect`, `screen_tap`, `screen_type`. Una propuesta de IA es una solicitud, no una acción ejecutada.
- `ToolExecutor`: solo publica estas herramientas si el servicio está conectado; exige confirmación para pulsar/escribir y marca ejecución solicitada, **no verificada**.
- Manifest y XML: autorización optativa en ajustes de Accesibilidad, sin reemplazar el servicio de teclado físico.
- `PhoneUsePolicyTest`: pruebas unitarias para restricciones de paquetes y selectores.

## Incremento P1.2: secuencias de pantalla verificables (20/10)
- `PhoneUseSequencePolicy` acepta como máximo **cuatro pasos** en JSON estricto. Tipos: `tap` (selector exacto + `expect`, inicialmente ausente) y `type` (selector exacto + texto de tamaño limitado).
- `PhoneUseService.sequence` reobserva la app antes de cada paso, efectúa **una sola** acción, espera hasta 1,5 s para verificar el resultado en la misma app y detiene toda la secuencia si cambia la app, falla la postcondición o se cancela. Las observaciones de UI nunca autorizan clicks a ciegas.
- No se permite otro `screen_tap`, `screen_type` o `screen_inspect` en paralelo a una secuencia.
- `ToolRegistry` y `ToolExecutor` ofrecen `screen_sequence` solo cuando el servicio está conectado. La herramienta requiere confirmación única del plan completo.
- `SettingsHome` incorpora «Control de aplicaciones» como acceso **opcional**, que abre directamente el panel de Accesibilidad del sistema; no activa nada automáticamente.
- `PhoneUseSequencePolicyTest` cubre JSON malformado, operaciones no permitidas, selectores extraños, límites de longitud/pasos y presencia de postcondiciones.
- El estado `VERIFIED` indica únicamente que se observó la postcondición **en la UI local**, no que un servidor externo confirmó un envío, compra o cambio.
- **Pendiente de validación**: compilación Android real, Gradle unit tests, lint, pruebas físicas de Android 16/One UI. Los tests añadidos están **escritos pero no ejecutados** con Gradle en este entorno.
- El flujo aún no es un agente visual iterativo capaz de descubrir selectores mediante IA en cada paso; eso requiere control explícito del contexto observado, límites de costo y revisión posterior.

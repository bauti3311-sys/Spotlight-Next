## Skills nativas y criterio de aplicación

Prioridad a [android/skills](https://github.com/android/skills) (Google, Apache2.0) y [chrisbanes/skills](https://github.com/chrisbanes/skills). Se consultan instrucciones concretas según el código, sin instalación masiva ni nuevas dependencias del APK.

- Google: `testing/testing-setup`, `jetpack-compose/jetpack-compose-performance`, `navigation/navigation-event` y `navigation/navigation-3`, `security/android-intent-security`, `security/android-permissions-security`. Elegir solo la relevante; Navigation3 no justifica migrar el historial actual. No aplicar ejemplos minSdk36 directamente a nuestra base26/compile35.
- Chris Banes: `using-chrisbanes-skills` enruta el problema; `compose-ui-testing-patterns` aplica pruebas de contrato de callbacks/gestos y mantiene integración donde importa el wiring. `compose-focus-navigation` para cambios de foco, `compose-state-and-effects` para ownership/cancelación, `compose-performance` con hipótesis medible; no afirmar rendimiento por inspección.
- Tests actuales: JUnit4, Robolectric, Compose UI Test y Roborazzi; SpotlightApp/callbacks son el seam existente. No instalar Hilt/Koin u otro framework para cambiar una fila. Pruebas instrumentadas requieren dispositivo; Robolectric no valida OneUI.
- Gradle: wrapper compacto de `gradle-run` para ejecución local. Adaptador externo al repo reutiliza el launcher Work existente, resuelve proxy dinámico por invocación, evita duplicar --console y rechaza --scan. No cambia código Android, dependencias, verificaciones, firma ni Actions.

## Primer uso práctico

La fila `ResultRow` tenía selección en `awaitFirstDown` del pase Initial. `SpotlightPanel` convierte la selección de archivo con navegación en Quick Look mediante LaunchedEffect; LazyColumn aún no había decidido que era un arrastre. La corrección deja a combinedClickable arbitrar el gesto y selecciona solo tras tap/long press/acción accesible confirmados. Se conservan geometría/materiales y teclado. Evidencia y resultados de pruebas se registran separadamente; esta descripción no afirma validación física.

## Próximas mejoras permitidas

Herramientas contextuales de Gemini desde el resultado actual, autorización exacta por solicitud y estado real por herramienta; luego navegación/restauración/cancelación. No enviar resultados locales al proveedor como efecto de seleccionar o desplazar. No ampliar el número inicial de resultados para mostrar estas funciones. Cada cambio necesita prueba dirigida y checkpoint antes de trabajo largo.
